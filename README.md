# TWINWV
TWINWV - True Warfarer is not a Warfarer Vocation (Vocation Swapper and Skills Switcher). Bind any of the 9 vocations to a hotkey and switch instantly. The mod automatically remembers whatever weapon, armor, and rings you had equipped on each vocation and puts them back on the moment you switch to it - no manual presets, nothing to save or load.
